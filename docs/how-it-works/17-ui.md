# 17. Страницы интерфейса

## Зачем нужно

React только показывает то, что уже посчитал сервер. Он не сравнивает пробы и не считает V. Исключение — подписи сроков и дат: словарь сроков продублирован в `src/utils/remediation.js`, даты переводятся в пояс браузера.

Каркас: `src/App.jsx`, маршруты ниже. Общий каркас страниц — `src/components/Layout.jsx`, меню — `Sidebar.jsx`. Закрытые маршруты оборачивает `ProtectedRoute.jsx`. Организация выбирается в `OrgGate` / контексте и хранится в браузере как выбранный id, не как источник прав: сервер всё равно проверяет членство.

Токен — `localStorage`, ключ `hardening_access_token` (`src/api/client.js`). База API — `VITE_API_BASE_URL` или `/api`.

Охват на странице агентов рисует не страница, а `src/components/AgentCoverage.jsx`. Графики — `ComplianceChart.jsx` и `TrendChart.jsx`.

Подписи ролей — `src/utils/roles.js`. Подпись источника снимка — `src/utils/collection.js`. Цвет процента — `src/utils/score.js` (пороги 50 и 80 только для цвета, на расчёт не влияют).

Кнопки изменения смотрят на `my-role === admin`: риск, политики, ключи, отправка выгрузки и анкеты. Сервер дублирует это `require_org_admin`. Спрятанная кнопка не заменяет проверку.

Старые адреса: `/project` ведёт на активы, неизвестный путь — на дашборд (`Navigate` в `App.jsx`).

## Ограничения

- Интерфейс не офлайн-приложение. Без API страницы пустые.
- Роли аудитор и наблюдатель на экране подписаны по-разному и ведут себя одинаково.
- Обязательная 2FA: пока она не подключена, сервер отвечает 403, и человек остаётся на экране подключения. Это решает сервер, не спрятанное меню.

## Вопросы на защите

**Где считается процент — в браузере?** Нет. Браузер показывает `compliance_score` из API. Цвет плитки — да, в `score.js`, на дробь он не влияет.

**Какая страница про находки БДУ?** «Уязвимости», маршрут `/vulnerabilities`. Методика — отдельная страница `/fstec`.

**Откуда кнопка скачивания агента?** Страница «Агенты» читает `/downloads/version.json`. Это статический файл nginx, не строка в PostgreSQL.
