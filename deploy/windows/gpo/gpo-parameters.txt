# Вкладка «Сценарии PowerShell»: имя сценария — путь к файлу в NETLOGON, эта строка — поле «Параметры».
# На странице «Агенты» после создания ключа площадки строка собирается сама: адрес и -Pin
# берутся из /downloads/version.json (server_url и server_pin), ключ подставляется один раз.

# Образец для https://audit.hardening-audit.ru на 8 ноября 2026.
# Замените КЛЮЧ_ПЛОЩАДКИ, КЛЮЧ_ПАКОВ и ДОМЕН.
# Пин ниже снят с боевого сертификата (SPKI SHA-256). Если сертификат сменят, берите server_pin

# Ключ площадки виден в SYSVOL. На ПК сценарий пишет его в site.key (только SYSTEM и администраторы)

# Время сбора в строку не входит: сценарий сам ставит 07:30 и разброс 2 часа
# (-CollectTime и -CollectRandomDelayHours). Задача досылки очереди включается тем же сценарием.
